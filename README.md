# NEXUS — Landing Page

Base estática simples para a landing page NEXUS — Design de Interiores & Construção.

## Estrutura

- `server.js`: servidor Express.
- `public/index.html`: página principal.
- `public/css/style.css`: estilos da página.
- `public/js/main.js`: interações da página.
- `public/assets`: imagens, ícones e fontes locais.

Execute `npm run dev` e abra `http://localhost:3000`.
